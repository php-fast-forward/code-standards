# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.6.0] - 2026-10-27

### Added

- Add explicitly enabled Magic Numbers and Rector workflow analyses with bounded native-report classification, advisory or blocking findings policies, always-visible summaries and failing operational errors. Expose native Rector JSON preview without granting semantic apply authority.

  Declare the project's consumer reusable call in a PR-only workflow while preserving push and manual project-quality testing.

  Keep Magic Numbers file selection independent from Rector's configured whole-project analysis.

  ([#75](https://github.com/php-fast-forward/code-standards/pull/75))

- Add explicit JSON check reports with native ECS findings, syntax results, incomplete-batch accounting and bounded nonstreaming capture; preserve default text and explicit fix behavior. ([#79](https://github.com/php-fast-forward/code-standards/pull/79))

### Changed

- Clarify the portable Code Standards skill with the supported command contract, complete optional-tool routes, native configuration examples and explicit installation ownership. ([#82](https://github.com/php-fast-forward/code-standards/pull/82))
- Keep the adapted PHPDoc skill's original MIT copyright and permission notice in
  its LICENSE file, removing the redundant separate NOTICE from the skill payload.

  ([#80](https://github.com/php-fast-forward/code-standards/pull/80))

## [0.5.0] - 2026-10-27

### Added

- Add an explicit `magic-numbers` command backed by published PHPMND, separate from check/fix. Reuse exact Git/PHP selection and consumer ignores, preserve native policy overrides and exit status, and offer deterministic native XML without loading consumer autoload implicitly. Document opt-in adoption, baseline limits and bounded invocation size. ([#66](https://github.com/php-fast-forward/code-standards/pull/66))
- Ship a dedicated portable PHPDoc authoring skill with concise interface-contract guidance, semantic-preservation checks and independent distribution references. ([#77](https://github.com/php-fast-forward/code-standards/pull/77))
- Migrate the documentation to a single reStructuredText guide rendered by the existing PHP phpDocumentor tooling covering installation, commands, configuration, workflow trust and troubleshooting. ([#29](https://github.com/php-fast-forward/code-standards/pull/29))

### Fixed

- Document the process interfaces' normative execution, output and failure contracts, explain capture/run/result selection, and preserve descriptive PHPDoc and inheritance markers through qualified native formatting and refactoring. ([#74](https://github.com/php-fast-forward/code-standards/pull/74))

## [0.4.0] - 2026-10-27

### Added

- Add development-only LLM Skills configuration for the bundled Code Standards skill, trusted Fast Forward Composer donors, Changelog and Dash artwork instructions. Keep documentation-authoring skills outside the synchronized sources. Introduce contextual Dash artwork for the repository README.

  Centralize distribution exclusions in Git export-ignore attributes, preserving runtime configuration, the canonical consumer skill and the README artwork.

  ([#33](https://github.com/php-fast-forward/code-standards/pull/33))

- Add a separate opt-in native Rector command with dry-run by default, explicit
  configuration and apply authority, empty-rule initialization protection and
  post-apply verification. Require an explicit native consumer PHP target before
  processing; keep target PHP, rules and caches consumer-owned;
  formatting check/fix never invoke semantic refactoring.
  Allow an explicit positive per-subprocess timeout without disabling bounds;
  execution timeouts fail with status 1, while cache configuration remains optional.

  ([#52](https://github.com/php-fast-forward/code-standards/pull/52))

- Expose optional lossless process capture with exact native exit codes and separate
  stdout/stderr bytes while preserving existing transport and provider contracts.

  ([#67](https://github.com/php-fast-forward/code-standards/pull/67))

- Add a reproducible, isolated Twig evaluation on the existing PHP matrix. Qualify
  native Finder/Git intersection, explicit configuration overrides, grammar parsing,
  deterministic native JSON and check/fix boundaries without adding a consumer CLI
  profile or changing the package's runtime dependencies.

  ([#68](https://github.com/php-fast-forward/code-standards/pull/68))

### Changed

- Composer(deps): bump symplify/easy-coding-standard from 13.3.8 to 13.3.9 in the composer-production group across 1 directory

  Update dependencies: `symplify/easy-coding-standard`.

  ([#57](https://github.com/php-fast-forward/code-standards/pull/57), @dependabot[bot])

### Fixed

- Avoid introducing PHP 8.0 parameter-list commas from the formatter's host runtime by default; preserve native consumer overrides and existing commas. ([#65](https://github.com/php-fast-forward/code-standards/pull/65))
- Ship the portable consumer skill with its MIT license and a self-contained
  check/fix procedure, qualifying optional refactoring against the installed CLI.

  ([#70](https://github.com/php-fast-forward/code-standards/pull/70))

## [0.3.2] - 2026-10-27

### Fixed

- Checks and fixes through ECS's public APIs without implicitly loading a separate
  consumer vendor autoloader. Preserves consumer cwd, native configuration and cache
  behavior, explicit custom-checker opt-in, and the tool's own Composer bootstrap.

  ([#55](https://github.com/php-fast-forward/code-standards/pull/55))

## [0.3.1] - 2026-10-27

### Changed

- Uses each external Action's published major channel: checkout v7, setup-php v2
  and Changelog's released v0 branch channel. Preserves workflow permissions,
  unprivileged PR checks and runtime provenance from the called job's actual SHA.

  ([#60](https://github.com/php-fast-forward/code-standards/pull/60))

## [0.3.0] - 2026-10-27

### Added

- Add weekly Dependabot checks for root Composer dependencies and GitHub Actions.
  Group minor and patch version updates separately for production and development
  Composer dependencies, and group GitHub Actions minor and patch updates. Keep
  major updates individual and leave security-update grouping at its defaults.

  ([#48](https://github.com/php-fast-forward/code-standards/pull/48))

### Changed

- Describes current usage and installs the compatible Composer package without a
  fixed release in the README example.

  ([#51](https://github.com/php-fast-forward/code-standards/pull/51))

- Apply the consumer's root and nested Git ignore rules dynamically to tracked candidates in full and changed scans, including force-added matching files. Preserve Git's negation, anchor, escape and directory semantics without a second parser or host-global excludes. Replace generated-directory name exclusions with consumer-owned rules while retaining structural Git metadata and source-containment protection. Ignore-rule changes, removals and renames trigger a complete eligible tracked scan; case-insensitive policy-name detection prevents missed invalidation on case-folding filesystems. ([#39](https://github.com/php-fast-forward/code-standards/pull/39))

### Fixed

- Uses the published Changelog 0.4.1 lifecycle's native repository and version title
  template when preparing or refreshing the managed version pull request, without
  overriding the generated title in this repository.

  ([#50](https://github.com/php-fast-forward/code-standards/pull/50))

## [0.2.0] - 2026-10-26

### Changed

- Organize the README around verified installation, commands, configuration, integration and compatibility, with source-backed badges, API summary and contributor guidance. ([#34](https://github.com/php-fast-forward/code-standards/pull/34))
- Use ECS 13.3's native non-risky PER Coding Style 3.0 set in place of PSR-12, preserving explicit command-attribute spacing and callback-last overrides. Keep destructive PHPDoc cleanup rules skipped so descriptions, inheritance markers, analysis types and intentional annotations survive formatting. Remove inactive conversion/global-import skips without implicitly enabling those rules. ([#40](https://github.com/php-fast-forward/code-standards/pull/40))

## [0.1.0] - 2026-10-26

### Added

- Introduces standalone non-risky ECS style configuration, explicit check/fix CLI,
  PHP syntax validation and exact-head changed-file checking with a portable
  consumer skill and reusable workflow examples.

  ([#7](https://github.com/php-fast-forward/code-standards/pull/7))
- Complete package metadata and portable skill discovery, declare direct container
  and Composer binary-runtime contracts, and validate metadata/platform in self-checks.
  Keep formatter data fixtures outside development classmaps during optimized installs.

  ([#25](https://github.com/php-fast-forward/code-standards/pull/25))
- Adds the released-only v0 workflow channel, exact executing-workflow runtime
  provenance and guarded conditional channel updates after verified 0.x publication.

  ([#13](https://github.com/php-fast-forward/code-standards/pull/13))

### Changed

- Composes the attributed invocable commands through the published Fast Forward
  Container autowiring API, with focused provider bindings and explicit overrides.

  ([#16](https://github.com/php-fast-forward/code-standards/pull/16))
- Record resolved legacy fixer rules, options and loaded-source provenance without broadening the initial default policy. ([#17](https://github.com/php-fast-forward/code-standards/pull/17))
- Verifies the compiled non-risky ECS preset and representative golden style,
  PHPDoc preservation and explicit fix idempotence contracts.

  ([#15](https://github.com/php-fast-forward/code-standards/pull/15))
- Place the tool's StandardsServiceProvider and composition tests in the
  ServiceProvider namespace, matching the provider's responsibility before the
  first publication. Third-party dependency-injection APIs remain unchanged.
  Use the published Container factories for lazy service bindings, preserving
  native autowiring, explicit scalar inputs and consumer overrides.

  ([#28](https://github.com/php-fast-forward/code-standards/pull/28))
- Documents the legacy PHPDoc rule activation and future analyzer boundaries,
  including native whole-project PHPStan scope, without enabling new policies.

  ([#19](https://github.com/php-fast-forward/code-standards/pull/19))

### Fixed

- Isolate the default ECS cache by executing checkout so another project's
  configuration invalidation cannot erase its cache, preserving explicit overrides.

  ([#23](https://github.com/php-fast-forward/code-standards/pull/23))
- Preserve whitespace and control bytes in checkout root names while rejecting nested, metadata and bare repository directories. ([#18](https://github.com/php-fast-forward/code-standards/pull/18))
- Skips non-PHP documentation symlinks before source-path validation while retaining
  symlink rejection for PHP and bin candidates, and pins workflow Actions to reviewed
  immutable commits.

  ([#7](https://github.com/php-fast-forward/code-standards/pull/7))
- Preserve each stacked contribution's verified implementation PR in release notes using explicit fragment metadata, rather than attributing every inherited fragment to the umbrella merge. ([#38](https://github.com/php-fast-forward/code-standards/pull/38))
- Loads the default ECS preset through symlinked Composer path installations
  without requiring a separate vendor directory beside the source checkout.

  ([#7](https://github.com/php-fast-forward/code-standards/pull/7))
- Validate the native executing-job JSON protocol before emitting immutable checkout
  identity, rejecting missing, ambiguous or malformed values without custom validators.

  ([#13](https://github.com/php-fast-forward/code-standards/pull/13))
- Verify each explicit formatter batch with a read-only check and propagate residual
  violations rather than reporting successful completion of a partially normalized file.

  ([#26](https://github.com/php-fast-forward/code-standards/pull/26))
