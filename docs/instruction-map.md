# Instruction map

The initial directory was empty and had no repository contracts. The shared host
bootstrap and Harness were read before implementation. This repository uses one
root `AGENTS.md`, following Changelog's single-root model: ordinary source, tests,
docs, Actions and workflow folders have no different maintenance authority.

`resources/skills/fast-forward-code-standards/SKILL.md` owns only the portable
consumer procedure. It is not copied to `.agents/skills` and needs no host alias.
Read root instructions, then only the linked domain guide or skill needed by
the task. The root Child DOX Index provides the reading route.

No previous instruction tree is migrated. Rollback restores the root contract,
its index and this map together through Git; it changes no host configuration.
