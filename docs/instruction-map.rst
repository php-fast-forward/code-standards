Instruction map
===============

The initial directory was empty and had no repository contracts. The shared host bootstrap and Harness were read before implementation. This repository uses one root ``AGENTS.md``, following Changelog's single-root model: ordinary source, tests, docs, Actions and workflow folders have no different maintenance authority.

``resources/skills/fast-forward-code-standards/SKILL.md`` owns the portable tool-consumption procedure; ``resources/skills/fast-forward-phpdoc/SKILL.md`` owns source PHPDoc authoring and review. These canonical payloads need no installed copy or host alias. Consumer installation and activation remain explicit. Read root instructions, then only the linked domain guide or skill needed by the task. The root Child DOX Index provides the reading route.

The opt-in refactoring guide remains under this same root authority. It records the native Rector invocation and executable-config boundary; it introduces no new instruction subtree, automatic semantic profile or consumer installer.

The opt-in Composer metadata guide also remains under root authority. Its root
index entry leads to the independent normalization/write/lock-hash contract;
ordinary source and test directories retain the same maintenance instructions.

No previous instruction tree is migrated. Rollback restores the root contract, its index and this map together through Git; it changes no host configuration.
